# CISA 초단기 합격 마스터

출퇴근길 스마트폰 한 손 학습용 CISA(국제공인정보시스템감사사) 웹앱. 설치·빌드 없이 브라우저에서 바로 열린다.

- **문제은행 5,300문항** — 2024 Job Practice 비중대로 D1 954 · D2 954 · D3 636 · D4 1,378 · D5 1,378
  - 모든 문항이 실전형 시나리오 + **4개 보기 전부에 정답 근거/함정 해설** + **ISACA 한 줄 공식**
  - **v2 실전 개정**: 4개 보기가 모두 같은 범주의 그럴듯한 선택지이고, 말장난이 아닌 개념 차이 하나로 정답이 갈린다. 부정형(NOT/EXCEPT) 문항 없음. 내용을 모르고 패턴만으로 찍을 때 정답률 19%(무작위 25%보다 낮음) — `node tools/check-staging.mjs --quality`로 측정
  - **v3 공식 형식 정렬**: ISACA 공식 QAE 샘플의 출제 형식에 맞춰 감사인 관점 43% · 80자 이하 짧은 지식형 36% · **ISACA 고유 관점** 문항 185개(상식과 다른 공식 입장 — 채점 후 배지 표시). 문제 풀기 필터에서 유형별로 골라 풀 수 있다
  - CAATs, COBIT, Agile/DevSecOps, PERT/CPM/EVM, OSI·방화벽·IDS/IPS, 제로 트러스트, SQLi/XSS/CSRF, DR 사이트 비교 등 빈출 시나리오 포함
- **핵심 요점 노트** D1~D5 (단원별 ★ 중요도, 비교표, 시험 포인트·함정) + **ISACA 10계명** + 키워드 공략법 + 한 줄 공식집
- **초압축 암기카드** 31덱 381장 (SoD 금지 조합, 샘플링 5종, RTO/RPO/WRT/MTD, 백업 복구 세트, FAR/FRR/CER, 암호화 vs 전자서명 키 …)
- **한 손 조작**: 다크 모드 기본, 하단 탭 바(홈/모의고사/오답노트/암기카드/ISACA공식), 하단 고정 버튼, 좌우 스와이프, 큰 터치 영역
- **ISACA 결정 키워드 자동 컬러 뱃지**: 가장 먼저(FIRST) · 가장 적절한(BEST) · 주된(PRIMARY) · 가장 큰 우려(GREATEST) · 가장 중요한(MOST)
- **학습 엔진**: 도메인·키워드·문항 유형(감사인 관점/짧은 지식형/ISACA 고유 관점)·풀이 상태(미풀이/오답/북마크)·난이도·토픽·검색 필터, 즉시 채점, 오답노트(연속 정답 시 졸업), 실전 모의고사(150/75/50/25문항 + 타이머), 이어서 풀기
- **자동 저장(localStorage)**: 풀이 기록·로그, 오답노트, 북마크, 도메인별 정답률, 일자별 CISA 환산 점수, 카드 진도, 모의고사 기록 — 백업/복원 지원

## 실행 방법

### 1) PC에서 바로 열기
`index.html`을 더블클릭하면 끝. (인터넷 없이도 동작, 글꼴만 시스템 글꼴로 대체됨)

### 2) 스마트폰으로 접속 (같은 Wi-Fi)
```bash
cd cisa
python3 -m http.server 8000        # 또는: npx serve .
```
PC의 IP(예: `192.168.0.10`)를 확인한 뒤 폰 브라우저에서 `http://192.168.0.10:8000` 접속 → 공유 메뉴의 **홈 화면에 추가**.

### 3) GitHub Pages로 어디서나 + 오프라인 (추천)
저장소 **Settings → Pages → Build and deployment → Deploy from a branch**에서 이 앱이 있는 브랜치와 `/ (root)`를 선택 → 잠시 후 `https://<계정>.github.io/<저장소>/` 주소가 생긴다.
폰에서 열고 **홈 화면에 추가**하면 앱처럼 실행되고, 한 번 열어 둔 뒤에는 **지하철 등 오프라인에서도** 서비스 워커 캐시로 동작한다(HTTPS 필요).

### 4) 안드로이드 앱(APK)
**다운로드: https://github.com/baekh601-cell/cisa/raw/HEAD/releases/cisa-master.apk**

폰에서 링크를 열어 내려받고 설치한다(처음 한 번 ‘출처를 알 수 없는 앱 설치’ 허용). 웹앱 전체가 앱 안에 들어 있어 **인터넷 없이 동작**한다.
- **업데이트 확인**: 앱을 열 때마다 `android/version.json`을 확인해 새 버전이 있으면 다운로드 안내를 띄운다(설정 → 앱 정보·업데이트에서 수동 확인 가능). 같은 서명 키로 빌드하므로 새 APK를 기존 앱 위에 설치해도 학습 기록이 유지된다.
- 앱 전용: 하드웨어 뒤로 가기(시트 닫기 → 이전 화면 → 홈 → 두 번 눌러 종료), 백업 파일을 다운로드 폴더에 저장, 화면 꺼짐 방지, 진동.
- 빌드: `ANDROID_HOME=<SDK 경로> tools/build-android.sh` → `releases/cisa-master.apk` (Gradle 불필요, JDK 17+·Android SDK 34 필요).
  새 버전 배포는 `android/version.json`의 `versionCode`를 1 올리고 `versionName`·`notes`를 고친 뒤 빌드해 APK와 함께 커밋하면, 설치된 앱이 다음 실행 때 알려 준다.
- 서명 키(`android/keystore/cisa-master.jks`)는 개인 학습용 앱의 업데이트 연속성을 위해 저장소에 포함했다. 앱이 요구하는 권한은 인터넷·진동뿐이다.

> 학습 기록은 **브라우저별로** 저장된다. 기기를 바꾸거나 브라우저 데이터를 지우기 전에 `설정 → 학습 기록 백업`으로 백업 코드를 복사(또는 파일 저장)해 두고, 새 기기에서 붙여넣어 복원한다.

## 사용 팁 (한 손 모드)

- 문제 화면: 보기 탭 → 하단 큰 버튼 **정답 확인** → **다음 문제**. 엄지가 화면 아래에서만 움직이도록 설계. 흔들리는 지하철에서 오터치를 막기 위해 기본은 2단계이며, `설정 → 원탭 채점`으로 1단계로 바꿀 수 있다.
- 좌우 스와이프로 이전/다음, 키워드 뱃지(ⓘ)를 탭하면 그 유형의 공략법이 뜬다.
- 홈의 **오늘의 10문제**는 도메인 비중대로 미풀이 문제를 뽑는다. **약점 집중 20**은 정답률이 가장 낮은 도메인에서 출제.
- 오답은 자동으로 오답노트에 쌓이고, 설정한 횟수(기본 2회)만큼 연속으로 맞히면 졸업한다.

## CISA 환산 점수 산정 방식

도메인별 **첫 시도 정답률**(처음 풀었을 때 맞혔는지 — 실전 예측력이 가장 높음)을 공식 가중치 D1 18% · D2 18% · D3 12% · D4 26% · D5 26%로 가중 평균한 뒤, 0~65%는 200~450점, 65~100%는 450~800점으로 선형 환산한다. ISACA는 환산식을 공개하지 않으므로 **합격선 450 ≈ 정답률 65%로 둔 근사치**다. 아직 풀지 않은 도메인은 가중치를 재정규화해 계산하고 홈에 표시한다.

## 파일 구조

```
index.html              앱 셸 + 데이터 로더
css/app.css             디자인 토큰(다크 기본/라이트) · 컴포넌트
js/core.js              저장소 · 데이터 인덱스 · 키워드 하이라이트 · 통계/환산 점수 · 세션
js/views.js             화면(홈/모의고사/퀴즈/결과/오답노트/암기카드/ISACA/노트/설정) · 이벤트
data/manifest.js        불러올 데이터 파일 목록 (확장 지점)
data/isaca.js           ISACA 10계명 · 키워드 공략 · 한 줄 공식집
data/notes/d1~d5.js     도메인별 요점 노트
data/cards/cards1~3.js  암기카드 덱
data/questions/d1~d5.js 문제은행 (ID = D1-0001 …, 학습 기록과 연결)
sw.js, manifest.webmanifest, assets/  PWA(오프라인·홈 화면 아이콘)
android/                안드로이드 앱(WebView 래퍼) 소스 · 아이콘 · 서명 키 · version.json(업데이트 확인용)
releases/cisa-master.apk  최신 안드로이드 APK
tools/                  문제 작성 가이드 · 검사기 · 문제/게시용/APK 빌드 스크립트
```

## 데이터 보강·확장

모든 데이터는 `CISA.addQuestions / addNote / addDecks / setIsaca` 등록 API로 들어오며, `data/manifest.js`에 파일 경로를 한 줄 추가하면 앱·오프라인 캐시에 자동 반영된다.

- **문제 추가**: `tools/AUTHORING_GUIDE.md` 형식으로 `staging/<팩이름>_D<1~5>_*.json` 작성 →
  `node tools/check-staging.mjs staging/<파일>.json` (스키마·키워드·해설 정렬 검사) →
  `node tools/build-questions.mjs` (기존 ID 보존, 신규 ID 부여, 중복·유사 중복 제거, 정답 위치 균등화)
- **노트·카드 추가**: `tools/CONTENT_GUIDE.md` 형식으로 파일 작성 후 `data/manifest.js`에 등록
- 데이터를 바꿨다면 `sw.js`의 `VERSION`을 올려 오프라인 캐시를 갱신한다.
