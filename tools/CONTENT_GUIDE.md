# 요점노트 · 암기카드 작성 가이드 (Content Guide)

새 노트·카드 덱을 추가하거나 보강할 때 이 형식을 따른다. 파일을 만든 뒤 `data/manifest.js`에 경로를 한 줄 추가하면 앱에 자동 반영된다.

## 1. 요점노트 — `data/notes/<id>.js`

```js
CISA.addNote({
  id: 'd1',                 // 고유 ID (영문 소문자)
  domain: 1,                // 1~5 (도메인 무관 노트는 0)
  title: 'D1 정보시스템 감사 프로세스',
  weight: 18,               // 출제 비중(%)
  summary: '한두 문장 요약',
  sections: [
    { title: '1. 단원 제목', stars: 3, body: `
## 소제목
- **용어**: 설명
  - 하위 항목
| 구분 | 내용 |
|---|---|
| 예 | 값 |
> 💡 시험 포인트: …
> ⚠️ 함정: …
` }
  ]
});
```

- `stars`: 3 = 빈출 핵심, 2 = 중요, 1 = 참고 (앱의 ‘★★★ 핵심만’ 필터에 사용)
- `body`는 JS 템플릿 문자열(백틱). 본문에 **백틱(`)과 `${` 사용 금지**.
- 지원 마크다운: `##`(소제목) `###`(작은 제목) `- 항목` `  - 하위 항목`(공백 2칸) `1. 순서` `**굵게**` `` `코드` `` `==형광펜==`
  표(`| a | b |` + `|---|---|`), `> 💡 …`(시험 포인트 박스), `> ⚠️ …`(함정 박스), `> …`(일반 박스), `---`(구분선)
- 내용 원칙: 한국어, 시험 대비 중심. 정의 → 비교표 → ISACA 관점 → 출제 포인트·함정 순으로 압축. 도메인 Job Practice 세부 주제를 빠짐없이.

## 2. 암기카드 — `data/flashcards.js` (또는 `data/cards/<이름>.js`)

```js
CISA.addDecks([
  { id: 'sod', title: '직무 분리(SoD) 금지 조합', tag: 'SoD', d: 2, desc: '한 줄 설명', cards: [
    { f: '앞면: 질문·용어', b: '뒷면: 답 (마크다운 가능, 250자 이내 권장)' }
  ] }
]);
```

- `id` 고유(영문), `tag` 4자 이내(덱 아이콘에 표시), `d` 도메인 번호(공통은 0)
- 앞면은 짧게(한 가지만 묻기), 뒷면은 핵심 답 + 한 줄 이유. 비교는 표 사용.
- 카드 진도는 `덱 id + 카드 순서`로 저장되므로, 기존 덱에 카드를 추가할 때는 **맨 뒤에 덧붙인다**.
